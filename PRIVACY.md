Effective Date: August 28, 2026Tkdb ("the Application") is a private, personal-use Discord application hosted on GitHub. This Privacy Policy explains how the Application handles data within the private Discord server(s) where it operates.Our core philosophy is simple: We respect your privacy, and the Application is designed to function without collecting your personal information.1. No Data CollectionThe Application does not collect, harvest, log, or store any personal data or personally identifiable information (PII). This includes, but is not limited to:Names, usernames, or email addresses.IP addresses or device information.Message histories or user metadata outside of immediate, real-time command execution.2. Real-Time Processing OnlyAny data processed by the Application (such as text commands or Discord user IDs required to execute a function) is processed in-memory and in real-time. This data is transient and is not saved to any permanent database, log file, or external cloud storage.3. Third-Party SharingBecause the Application does not collect or store any information, no data is ever sold, rented, shared, or transferred to third parties.The Application operates strictly through the official Discord API and is subject to Discord's Developer Terms of Service and Privacy Policy. It does not use any additional third-party tracking, analytics, or advertising tools.4. Hosting and InfrastructureThe Application's source code is hosted on GitHub. GitHub may collect technical metadata (such as access logs) in accordance with GitHub's own Privacy Policy. However, the Application itself does not transmit any user data from Discord back to GitHub.5. Changes to This PolicyBecause this is a personal-use, non-data-collecting application, this policy is unlikely to change. If the functionality of the Application is updated in the future to require data storage, this document will be updated to reflect those changes before they take effect.6.
