For server admins

Setting up My Tkdb

How to add the bot to your server, give it the right permissions, and turn on the two server features: call-out encounters and inspector missions. Takes about five minutes.

Steps

  1. Before you start
  2. Invite the bot
  3. Set up the channel
  4. Turn on encounters
  5. Turn on missions
  6. Add a ping role
  7. Countdown channels
  8. If something's wrong
1

Before you start

  • You need the Manage Server permission (or Administrator) in your Discord server. The setup commands only show up for people who have it.
  • Decide which text channel the bot will post in. One channel handles both encounters and missions. A new channel such as #darkwick-board works well.
  • Players don't need anything special. /roam, /meet, /affinity and the rest work anywhere once the bot is in the server.
2

Invite the bot

  1. Open the bot's invite link and pick your server.
  2. Make sure both of these are ticked on the invite screen: bot and applications.commands. Without bot, the bot can't post in channels and shows as offline.
  3. Leave the permissions below ticked and press Authorize.

Already invited it before?

Running the invite link again is safe. It won't add a second bot or reset anyone's progress. It only updates the permissions.

3

Set up the channel

Even if the bot has the right permissions server-wide, a channel can block it. Check the channel's own settings:

  1. Right-click the channel (or long-press on mobile) and choose Edit Channel.
  2. Go to Permissions. Under Advanced permissions, press + and add the bot's role (it has the bot's name).
  3. Set the bot's permissions to match the first table below, then press Save Changes.
  4. Check the @everyone row (or your member role) against the second table.

Tip

A read-only channel works best: members can see posts, click buttons and use slash commands, but can't chat. Slash command replies are private, so nobody's guesses clutter the board.

4

Turn on encounters

Encounters are the public guessing game. Every so often the bot posts a black silhouette of a character, and the first person to name them wins.

  1. In any channel, type this and pick your encounter channel:
    /encounters channel channel:#your-channel
  2. The bot sends a short test message in that channel. If you see it, you're done. If you don't, go back to step 3.
  3. Run /encounters status any time to check it's running.

What your members will see

  • A silhouette shows up at random, somewhere between 45 minutes and 3 hours after the last one.
  • Each one stays open for 2 minutes. Players guess with /call, for example /call Sho.
  • A wrong character name means a 10-second wait before guessing again. A typo costs nothing.
  • The winner gets a reveal card and a bonus point on their next /roam or /meet with that character. If nobody gets it, the post just says the moment has passed.

Encounter commands

5

Turn on missions

Missions are requests posted on a board with an Accept button. The first person to click takes the mission, and only they find out what it is.

  1. Type:
    /missions enable
    If you already set up encounters, that's all you need. Missions post in the same channel.
  2. To use a different channel instead, add it: /missions enable channel:#other-channel. Give the bot the same four permissions there (see step 3).
  3. The bot sends a test message: "Mission requests will come through here." If it appears, missions are on.
  4. Run /missions status any time to check.

How missions work for members

  • Six requests a day, at random times between 5 AM and midnight. The times change every day.
  • A request nobody accepts disappears after 2 hours.
  • Each player can hold one mission at a time and accept up to two a day. They have 48 hours to finish it.
  • After accepting, the player runs /mission to see their instructions. It tells them which of the three types they got:
TypeWhat the player doesFinish with
RiddleReads a report about a student and works out who it is./riddle
ErrandMeets a few students from one house through /roam or /meet to collect their signatures./docs
Co-opCalls for help. The first other player to join finishes it with them./mission assist:true

Rewards are house logs (which raise their rank in /house) and a saved cooldown reset they can spend when /roam or /meet asks them to wait.

6

Add a ping role

Optional

If you want members to get a notification when a new encounter or mission appears, make a role for it. The bot finds it by name, so there's nothing else to set up.

  1. Go to Server Settings → Roles → Create Role.
  2. Name it exactly tkdb-inspectors (capital letters don't matter).
  3. Turn on Allow anyone to @mention this role. Without this, the bot can't ping it.
  4. Let members give themselves the role, for example through Onboarding or Channels & Roles.

Only members with the role are pinged. No role means no pings, and the posts still go up as normal. It can take up to 10 minutes for the bot to notice a new role.

7

Countdown channels

Optional

A channel whose name counts down to the next Tokyo Debunker Wishing Well, like 💎 Wishing Well: in 6 days, or to your own server events. This is separate from encounters and missions.

  1. Pick a voice channel, stage channel or category. Text channels don't work because Discord changes their names to lowercase.
  2. Give the bot View Channel and Manage Channels on that channel.
  3. Run /countdown wishingwell channel: and pick the channel. For your own events, add them with /event create, then run /countdown customevent channel:.
  4. Days flip at midnight US Pacific time. To change that, use /countdown timezone.

If something's wrong

I can't see /encounters or /missions

You need Manage Server. If you have it and still can't see them, open Server Settings → Integrations → the bot, and check nobody has hidden those commands from your role.

No test message showed up

The bot is missing a permission in that channel. Go through step 3 again. Look for a red ✗ on the bot's role, or on a category the channel belongs to, then rerun the setup command.

Status says "Stopped" or "Running, with errors"

After 3 failed posts in a row, the bot stops posting so it doesn't keep failing. Fix the channel permissions, then run /encounters channel or /missions enable again to restart.

Members get "only works in the encounter channel" from /call

That's on purpose. /call only counts in the channel you picked in step 4. Make sure members have Use Application Commands there.

The bot shows as offline

It was probably added without the bot option. Use the invite link again with both bot and applications.commands ticked.

A member isn't getting bond scene DMs

They need DMs from server members turned on: click the server name → Privacy Settings → Direct Messages. They can also check /bonds dms:on.

The ping role isn't pinging

Check the name is exactly tkdb-inspectors and Allow anyone to @mention this role is on. Give it up to 10 minutes after creating or renaming the role.
